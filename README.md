CampusCare – Institute Issue Management System

CampusCare is a MERN-based institute issue management platform designed for students and staff to efficiently manage and track institute-related issues.

Features

- Role-based authentication for students, staff, and administrators
- Issue reporting and tracking system
- Status updates and category-wise issue filtering
- Dashboard-based workflow
- Responsive user interface

 Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js

Future Enhancements

- AI-based issue categorization
- Smart issue handling and automation
- AI-assisted support workflows

Deployment

Live Project: https://campuscare-green.vercel.app
